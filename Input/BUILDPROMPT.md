# RIGSTORM HUB — BUILD PROMPT V1

## 01 — PROJECT

Build **RigStorm Hub**, the central digital headquarters and ecosystem directory of **RigStorm Group of Companies**.

RigStorm Hub is the central place where people can understand the RigStorm ecosystem, explore every company, understand what each venture does, and access its official digital presence.

This is NOT a normal marketing landing page and NOT simply a collection of links.

It should feel like:

**A premium company ecosystem + digital headquarters + central directory.**

The entire website must be **static-hostable on GitHub Pages**.
